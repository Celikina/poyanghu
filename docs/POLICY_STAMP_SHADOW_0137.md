# 0.1.37 政策盖章与卡牌阴影

基于 Celikina main `b8ba2ef` 修改本地游戏。

- 成就定义和结算触发删除一项隐藏成就，成就页与统计保留四项。旧成就存档只加载仍存在的定义，删除项不会再次显示或弹出。更新日志历史文字同步清理。
- 水位上下界参考线在填充条、波纹和预览上方显示。绿线不透明度为 45%，保留底下连续的蓝色水位条；上下各突出 1 个设计像素。
- 政策力度使用用户交付的卷轴图。按档位显示对应页脚与唯一印章；点击格子盖章，印章落下后轻微回弹，另外两格留空。原来的费用规则、已选牌档位与一秒切档冷却保持一致。减少动态模式直接显示落定印章。
- 阴影从实际牌面透明轮廓提取凸轮廓，并使用等比显示后的牌面区域投影。手牌、牌库、紧急调度、知识卡及其详情共用处理。
- 原来的发牌飞行会跳过陀螺仪更新，阴影停在之前的姿态，到手后才重新投影，产生可见跳变。现在在渲染前读取当前实际位置、缩放、旋转与倾斜，复用同一个阴影网格资源更新；不变的姿态使用缓存，落定后不会再改变形状。

素材导入：`python tools/import_policy_stamp.py <政策力度II目录>`。从三个示例图中分离透明印章以支持盖章动画，保留其余标题、档位和说明的原始画面。

合计 1815 项。阴影网格与直接多边形绘制的差异不超过一个颜色量化级，显著差异像素为零。1280×720 与 960×540 截图已目视检查。

卡牌交互测试中两条原有失败用原版阴影对照也能复现。原因是测试停掉游戏更新后未继续驱动手牌回位；补齐测试中的正常更新路径后通过，没有改变生产代码中的拖动规则。阴影渲染测试也补充等待牌面容器布局完成，避免验证尚未形成的几何。
