# 0.1.41 知识卡掉落实拍图

四十张实拍知识卡在游戏内掉落时，直接读取已有的对应 `assets/art/knowledge/photos/<kid>.png`，和原有知识说明共同展示。无需进入图鉴才能看到实物；没有新增图片或改变素材许可。

- 保留蓝色像素弹窗、金色标题、原有说明和「收下（继续）」按钮，照片使用浅色相框与平滑采样，保持正方形比例。
- 宽窗口为左图右文，较窄窗口为上图下文，调整窗口时即时重排。文字区域按实际内容高度收缩，超过可用高度时允许滚动；按钮固定在正文下方。
- 原有打字机与两次点击的行为保持：第一次补全正文，第二次收下并继续队列。连续掉落复用相框节点，不累积控件。
- 存档额外记录当前知识卡 id，继续游戏时恢复照片；旧存档按原有知识卡标题恢复对应 id。无法识别的旧内容继续使用原文字弹窗。
- 非实拍的狄鑫斛彩蛋保留原来的闪光卡片演出。普通事件、结算及报告恢复原有文字布局，不携带知识卡照片。
