# 0.2.2 照片翻看方向与游船航行

主界面删除左右按钮，手动翻页仅保留拖动；点击仍可查看原图。主界面滚轮与方向键不再翻页，放大后方向键继续可用，原有闲置轮播和悬停暂停保持。

- 右拖：当前照片留在原位，上一张从左侧出现。拖动距离除以照片宽度得到进度，上一张从 `-宽度` 移向 `0`，透明度从 `0` 增到 `1`。
- 左拖：下一张留在原位下方，当前照片向左移动，透明度随距离从 `1` 减到 `0`。
- 达到翻页条件后从释放时的位置、透明度继续动画；不足阈值时回位，方向反转即时恢复对应照片。放大仍隐藏相册内容。
- 大图按钮以固定观看区域定位，不读取当前图片宽高。13 张照片切换时左右按钮坐标一致，图片继续按各自的原始比例显示。

长江游船原来沿许多细小 OSM 折点改变朝向，绘制时又用两次取整后的坐标差计算船头方向，因此匀速移动也会出现朝向抖动。新航线仅供游船使用：在原河道中心线的 0.003 UV 误差内略过细小折点，弯道做短二次贝塞尔过渡，按累计长度采样并插值连续切线。长直航段保持固定朝向，湖口等弯道保持转向。河道地形、边界和通航左右分流不变。

游船位置与方向用未取整的投影计算，去掉额外的正弦上下摆动；原船只贴图、数量与行进速度参数保持。航线节点和累计长度只在构建河道时生成，每帧仅一次二分采样，省去原来的额外前后两次路线采样。
