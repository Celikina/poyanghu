# 0.2.3 快速拖曳相册稳定性

复现：连续短拖取消，在回位动画未完成时再次拖动，旧偏移被作为新起点重复相加；快速反向时也可能把上一轮的位移继续叠加。修复前的压力测试出现 413.6 像素的累计偏移，超过照片的 356 像素宽度，后方相纸越露越多。

新一轮按下时，保留当前照片的有效姿态，清理另一张相纸的遗留状态。未完成的回位在按住期间继续收束，当前拖动只叠加本轮距离，最终位置限制在一张照片的宽度内。透明度由位置重新计算，不再反复乘上上轮透明度。结束后两张相纸都重置位置、旋转、缩放和透明度，只显示当前照片。放大图片同时结束未释放的手势。

继续允许快速连续翻页和反向拖动，不等待动画完成，不新增操作冷却。保留右拖上一张从左侧显现、左拖当前照片淡出的方向规则和固定大图按钮。

独立测试目录：`outputs/photo-stability-0203/`。使用独立用户目录，不改动玩家存档。

| 检查 | 结果 |
| --- | --- |
| 120 次短拖取消并中断回位，30/60/120 FPS 下合计 1800 次快速甩动与反向操作，残留层清理 | 14 项聚合检查通过 |
| 原有相册检查及真实窗口连续快速拖动 24 次 | 201 项通过 |
| 原图比例、出处、放大翻页和关闭探针 | 24 项通过 |

合计 239 项检查通过。短拖取消压力场景最大偏移从修复前约 413.6 像素降至约 49.7 像素；快速甩动时所有相纸保持在 356 像素的固定行程内，停止后完整归位。截图 `07-after-rapid-swipes.png` 已目视确认相册恢复正常叠层。
