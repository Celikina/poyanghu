# 0.1.27 候鸟监测与判负

候鸟总量为留湖候鸟与当季迁徙候鸟之和。白色左段显示留湖数量，静态半透明白色右段显示迁徙数量；增长预览保持闪烁白色，损失预览保持闪烁红色。

固定红线 = ceil(开局留湖候鸟 × 难度比例)。简单80%、普通85%、困难88%、噩梦90%。开局60时分别为48、51、53、54。开局天赋计入留湖数量，红线初始化后不随季节、损伤、恢复或迁徙移动。

总量严格低于固定红线才判负，等于红线安全。自然迁出会降低总量，并可导致判负。预览、红线绘制、危机提示、失败报告使用同一口径。生态评分和拨款保留原有内部留湖种群口径。

存档同时保存开局留湖数量与固定红线。旧存档未记录开局数量，首次读入以当时留湖数量建立基准，之后随新存档固定保存；不改写旧存档当前鸟群数量。
