# 0.1.38 刷新状态与动画开销

刷新操作在扣费、标记本回合使用后同步更新文字和禁用状态，再开始收牌与准备新牌。碎裂时只移除按钮背景，保留占位及立即可见的「本回合已刷新」文字；下一回合恢复原按钮样式。避免重复点击扣费。

优化保留游戏规则、随机抽牌、发牌与排序时长、音效、阴影形状、柔化层数和碎片轨迹：

- 同一种牌面模板共用实际透明轮廓，不再为每个金额、标题和照片重复读取图像。自定义牌面仍按纹理区分。
- 卡牌姿态变化只上传阴影顶点，复用网格表面、颜色和三角索引。静止时复用几何；渲染前仍同步位置与倾斜，保持落定阴影稳定。
- 指标目标相同时保留当前动画；改变目标或取消动画后仍正常恢复，原 0.35 秒过渡不变。
- 政策按钮锁定状态没变化时跳过重复设置。每块碎片将运动和延迟销毁合并为一个 Tween，仍生成九块、仍在 1.4 秒清理。

同机实测（Godot 4.7.2，OpenGL Compatibility，RTX 4060 Laptop）。移动测试为同一张实际手牌的 1000 次位置/倾斜更新；静止测试为 10000 次相同姿态检查。数字仅代表该组件 CPU 基准，不是整机帧率承诺。
