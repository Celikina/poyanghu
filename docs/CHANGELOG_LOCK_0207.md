# 0.2.7 更新日志密码锁

更新日志入口现在先显示密码解锁界面，每次打开都重新验证。仅正确密码会创建并显示日志条目；关闭、切换菜单或隐藏主菜单时清空输入、删除已显示的日志节点并重新上锁。不保存解锁状态。

- 密码使用系统安全随机数生成，共 256 位随机熵、43 个 Base64url 字符。固定密码单独交付用户，仓库与测试文件不保存明文。
- 校验文件仅保存随机盐与 SHA-256 摘要，比较摘要时遍历全部字节。
- 密码输入隐藏字符，支持粘贴和回车提交；返回按钮与 ESC 均可关闭。
- 连续输错三次后等待 5 秒，继续输错会递增等待至最多 30 秒。关闭再开不能绕过当前等待，成功解锁才重置失败计数。
- 本地离线 UI 密码锁用于阻止普通玩家通过游戏界面查看，不保证防程序逆向或修改客户端；游戏内日志数据仍属于随客户端发布的资源。
