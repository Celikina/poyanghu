# 0.1.40 盖章音效、按剩余张数刷新与音量条

- 政策选择成功后，印章缩到落纸位置（0.10 秒）时播放一次 0.23 秒盖章声，使用现有音效池及音量设置。冷却、当前档、无效输入和初始化不会响；减少动态模式的成功切档直接播放一次。
- 使用 Sonilo 音效库现成素材 Rapid Rubber Stamp Presses。素材页面明确允许免费商用、无需署名；服务条款 6.4 以音效库页面许可为准。原始录音、页面证据在 `outputs/stamp-refresh-0140/`，来源与处理记录在 `licenses/policy-stamp-sonilo.txt`。不是免费账号自行生成的非商用素材。
- 刷新前统计当前剩余的普通手牌，重抽相同张数。已出牌、调度牌及其锁定档位保持；费用始终为 5 万，不按数量变化，每回合仍限一次。没有手牌时按钮禁用，不扣费、不消耗机会；退回一张后可刷新这一张。发回音效由实际新牌数计算，保留原有最长时长。
- 例：原有七张，打出四张后刷新剩余三张，桌牌加手牌仍七张，四张退回后仍七张；不再补成十一张。额外抽牌形成九张手牌时，刷新仍维持九张。
- 主菜单和暂停设置移除左侧白色「音量」标签及占位，滑条占据对称的面板内容区，百分比仍在下方。两个设置页和音量行为保持同步。
