# 0.1.39 刷新手牌音效

刷新完成收牌、抽取及牌面准备后，将新牌发回视为独立音效批次。此前被本回合首次发牌的标记拦截，现在新牌开始飞回时播放一次同一段授权录音。

仍由实际动画中的发回张数计算时长：`0.54 秒 × min(实际张数 / 7, 1)`。一张约 0.077 秒、三张约 0.231 秒、七张或以上最多 0.54 秒。已出到桌上的牌不参与统计，零张不播放；重新排序继续沿用原有按其发回动画时长计算的上限。

独立存档测试结果：发牌、排序、刷新、短批次及早结算音效 115 项通过；即时刷新文字、碎片寿命和指标动画 14 项通过，均零失败。满手牌测试实际点击刷新并监测音频起止；一张和三张使用刷新相同的保留桌牌、构建新牌和发回路径，核对有效音频长度和仅播放一次。
