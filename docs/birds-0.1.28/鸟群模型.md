# 0.1.28 鸟群环境系数

T=B+M，上限100；B为留鸟与夏候鸟种群基数，范围0–60；M为冬候鸟迁徙群，范围0–40。季节容量为春8、夏4、秋20、冬40。

环境适宜度H共用沉水植被40%、水质30%、水位适宜性30%的权重，保留严重植被/水质短缺约束；鱼类低值不再另外限制鸟群。内部食物损失仍降低H，不在牌面显示。

共同系数 C=clamp((H−20)/60,0,1)。H≥80时C=1，冬季完整迁入40；H=50时C=0.5，迁入20；H=23时C=0.05，迁入2。

B以开局或最近出牌后的数量和当时环境作为参照，按新旧C的比例变化，限制在0–60；M以当季容量乘同一C，再扣实际受伤和次年迁入遗留。环境不变时不会每回合重新乘一遍比例。参考量使用整数保存，避免JSON浮点精度使读档后的预览发生偏差。

例如B=60、M=40、C=1的冬季，C下降到0.5后B=30、M=20。环境不变而转到春季，B仍为30，M变为4。季节只改变M的容量，不额外对B扣季节分。

旧存档B>60时，将超过60的部分归入M，保留T和伤亡历史。旧开局基数大于60时，首次升级同时将其红线调整到60对应的原难度比例；此后仍固定。已有合法基数及红线保持原值。
